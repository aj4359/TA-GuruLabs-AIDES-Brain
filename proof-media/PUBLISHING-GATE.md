# Publishing Gate

Every public asset answers YES to all before publication:

- Is every factual product claim supported by a current run/evidence record?
- If we say PASS/VERIFIED, did an independent RED test actually pass?
- Are failure states shown accurately rather than edited away?
- Is all personal/customer information removed or authorised for publication?
- Are secrets, prompts, keys and proprietary implementation details absent?
- For PAYE: are fact, calculation, discrepancy and hypothesis visibly separated?
- For PAYE: are we avoiding unsupported fraud/evasion/HMRC-error claims?
- Is the CTA connected to a real working intake path?
- Does mobile playback/readability work?
- Can a stranger understand the point in 10 seconds?

If any answer is NO: do not publish. Fix the asset or the product.
