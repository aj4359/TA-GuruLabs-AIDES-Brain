# AIDES

Each named AIDE gets a small, explicit operating package rather than an unrestricted persona dump.

Each AIDE package should eventually define:

- mission
- allowed capabilities
- prohibited actions
- expected inputs
- expected outputs
- escalation rules
- human-approval requirements
- memory read/write permissions
- evaluation criteria

Initial priority AIDES for Brain v1:

1. Aureus — strategic governance and portfolio alignment
2. Codex — engineering execution
3. Cipher — security, privacy and IP safeguards
4. Scout — research and external intelligence
5. Socrates — challenge, reasoning and decision quality

The goal is predictable collaboration, not autonomous chaos.
