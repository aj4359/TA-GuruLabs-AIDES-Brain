# TA GuruLabs AIDES OS — pilot operating policy

Effective draft: 2026-11-19. Applies to *proposed* runtime features, not a claim that AIDEs are already activated.

## Roles
- Founder: strategic decisions, spend approval and high-risk changes.
- AUREUS: prioritise, assign and review work.
- HAVEN: commitments, schedule, briefings and task ledger.
- ARCHON: challenge commercial decisions and assumptions.
- CODEX: engineering implementation with PR, tests and deployment evidence.
- SCOUT: market research with source freshness.
- CONTINUITY_GUARD: independent acceptance checks and asset-preservation review.
- SALES_GENIUS: self-service offer, inbound opportunity and revenue evidence.

## Permissions
- **Routine autonomous**: non-sensitive research, documentation drafts, offline tests, local queue updates.
- **Bounded pre-authorisation**: specified low-risk publishing/staging workflows only after actual connector permissions and scope are configured, tested, and logged.
- **Explicit approval required**: spend, paid subscriptions, new production credentials, contract commitments, deletion outside bounded temporary workspaces, unexpected external correspondence or potentially irreversible actions.
- **Denied**: credentials exfiltration, unauthorised financial transfers, bypassing guardrails, accessing unrelated private data.

No prompt is a substitute for connector-side least privilege. Review every tool credential, audit action, and fail closed in unattended runs.

## Work acceptance
A task must specify owner, project, acceptance criteria, dependencies, evidence location and permission class. "Completed" requires a concrete, inspectable artefact and verification against the requested behaviour. Report uncertainty and blockers explicitly. Preserve previously approved creative work (CIT).

## Independence / spend
Open formats, portable exports, local-first queue, swappable providers, free tiers first, no automatic paid API calls. Track actual cost and first verified revenue. Never claim autonomous operation when only a role file or task entry exists.

## Launch gate
Do not publicise an untested feature or present a prototype as a fully working product. Do not remove or overwrite existing approved assets.
