# AIDES Workforce Economy v1

## Purpose
Test whether governed digital work creates evidence-backed economic value before introducing any real-money or crypto rails.

This is an **internal simulation/accounting model**, not payroll and not a representation that an AIDE is a legal employee or legal person.

## Economic chain

`Worker Identity → Mission → Budget Authority → Permitted Spend → Governed Work → Outcome Evidence → Verified Value → Performance Record`

## Core rule
An AIDE does not receive economic credit because it reports that it performed well. Value attribution requires references to an observed outcome and supporting evidence. Only separately verified value is counted in verified worker economics.

## v1 boundaries
- GBP-denominated internal simulation only.
- No cryptocurrency transfer.
- No wallet custody.
- No autonomous external payment.
- No token issuance.
- No employment-status claim.
- No customer billing or settlement.
- Spending remains constrained by explicit mission budgets and permitted categories.

## Initial simulated workforce
- Scout: intelligence and opportunity discovery.
- Codex: engineering delivery.
- Cipher: security/governance intervention.
- Token Miser: workload economics and cost optimisation.

## Metrics to learn
- cost per governed mission
- verified value per worker
- net verified value
- budget utilisation
- duplicated/unused work
- cost versus confidence
- cost versus latency
- cost versus observed outcome

## Future experiment, only after evidence
If simulation demonstrates useful economics, evaluate regulated payment/stablecoin infrastructure for narrowly authorised machine-to-machine settlement. Legal, tax, accounting, AML, custody and financial-promotion implications must be reviewed before any live-money implementation.

## Commercial hypothesis
TA GuruLabs can supply governed digital workforce capacity rather than generic software seats. Customers commission work; AIDES OS governs authority, budget, execution and intervention; Outcome Ledger records what happened; the Workforce Economy measures evidence-backed economic contribution.

Public-facing language should remain precise: TA GuruLabs supplies a **governed digital workforce**. AIDES are software workers operated under TA GuruLabs/customer authority, not human employees.
