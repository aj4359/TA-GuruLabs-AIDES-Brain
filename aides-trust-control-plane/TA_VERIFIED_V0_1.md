# TA VERIFIED v0.1

A product claim is not verified because code exists. A verified release requires:
claim → acceptance criteria → scenario → evidence → failure/correction history → result → version/timestamp → limitations → release decision.

This record is shared across PAYE Forensics, AIDES, AEGIS, JWMP and other TA GuruLabs products.

Dynamic workers/tools/models are replaceable. The evidence obligation is not. Discovery may use external/open standards; TA GuruLabs owns the authority, economics, evidence, outcome and learning layer.
